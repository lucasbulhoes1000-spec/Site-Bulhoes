# Bulhões Odontologia — Site V1

Estrutura inicial do novo site da Bulhões Odontologia em Next.js, pronta para GitHub + Vercel.

## Como rodar localmente

```bash
npm install
npm run dev
```

Depois abra `http://localhost:3000`.

## Deploy na Vercel

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para o repositório.
3. Na Vercel, clique em **Add New Project**.
4. Importe o repositório do GitHub.
5. Framework: **Next.js**.
6. Clique em **Deploy**.

## O que está propositalmente como placeholder

- Telefones / WhatsApp
- Endereço
- Horários
- CROs
- Números de casos
- Integrantes da equipe
- Imagens reais
- Depoimentos
- Links de páginas internas

## Onde editar o conteúdo

- Página: `app/page.js`
- Cores e layout: `app/globals.css`
- Metadados/SEO inicial: `app/layout.js`
- Imagens temporárias: pasta `public`

## Observação

Esta é uma V1 visual/estrutural. O objetivo é validar hierarquia, proporção, seções, ritmo, cores e responsividade antes de substituir por conteúdo e imagens reais.
